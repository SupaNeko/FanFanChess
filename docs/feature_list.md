# Feature List - 翻翻棋在线对战

## 1. 用户系统

| 优先级 | 功能 | 描述 | 状态 |
|--------|------|------|------|
| P0 | 用户名注册 | 输入用户名，唯一性校验，无密码 | 待开发 |
| P0 | 用户绑定 | 用户名作为唯一标识，绑定WebSocket连接 | 待开发 |
| P1 | 用户状态 | 在线/游戏中/观战状态显示 | 待开发 |

## 2. 本地模式

| 优先级 | 功能 | 描述 | 状态 |
|--------|------|------|------|
| P0 | 本地对局 | 单个用户控制双方，轮流操作 | 待开发 |
| P0 | 随机棋盘 | 后端随机打乱32枚棋子位置 | 待开发 |
| P0 | 先后手判定 | 抛硬币动画，随机决定先手 | 待开发 |
| P0 | 颜色绑定 | 先手翻棋后确定双方阵营 | 待开发 |
| P0 | 完整规则 | 移动、吃子、翻棋、胜负判定 | 待开发 |

## 3. 联机模式

| 优先级 | 功能 | 描述 | 状态 |
|--------|------|------|------|
| P0 | 创建房间 | 生成6位随机邀请码 | 待开发 |
| P0 | 加入房间 | 输入邀请码加入 | 待开发 |
| P0 | 玩家/观战区分 | 前两位为玩家，后续为观战者 | 待开发 |
| P0 | 准备机制 | 玩家点击准备，双方准备后开服 | 待开发 |
| P0 | 实时对战 | WebSocket实时同步操作 | 待开发 |
| P1 | 断线处理 | 玩家断线提示，基础重连 | 待开发 |

## 4. 游戏逻辑

| 优先级 | 功能 | 描述 | 状态 |
|--------|------|------|------|
| P0 | 棋盘管理 | 4x8棋盘，32位置，棋子状态 | 待开发 |
| P0 | 移动验证 | 横竖一格，边界检查 | 待开发 |
| P0 | 吃子验证 | 大小比较，特殊规则，炮隔子吃 | 待开发 |
| P0 | 翻棋机制 | 翻开暗棋，无位置限制 | 待开发 |
| P0 | 胜负判定 | 吃光对方/投降/和局 | 待开发 |
| P1 | 悔棋功能 | 请求-同意机制，回退一步 | 待开发 |

## 5. 数据记录

| 优先级 | 功能 | 描述 | 状态 |
|--------|------|------|------|
| P1 | 对局存储 | 每局记录保存到数据库 | 待开发 |
| P1 | 历史操作 | 记录每一步操作 | 待开发 |
| P1 | 用户绑定 | 对局记录绑定参与用户 | 待开发 |
| P2 | 复盘功能 | 回放历史对局 | 待开发 |

## 6. 前端界面

| 优先级 | 功能 | 描述 | 状态 |
|--------|------|------|------|
| P0 | 登录页 | 用户名输入，简洁设计 | 待开发 |
| P0 | 模式选择 | 本地/联机两个入口 | 待开发 |
| P0 | 联机大厅 | 创建/加入房间 | 待开发 |
| P0 | 房间页 | 玩家列表，准备按钮，邀请码 | 待开发 |
| P0 | 游戏棋盘 | 横置4x8，棋子渲染 | 待开发 |
| P0 | 棋子统计 | 左右两侧显示剩余棋子 | 待开发 |
| P0 | 回合提示 | 顶部显示当前回合 | 待开发 |
| P0 | 规则浮窗 | 右上角按钮，hover显示规则 | 待开发 |
| P0 | 上一步提示 | 高亮显示对方上一步操作 | 待开发 |
| P0 | 抛硬币动画 | 决定先后手时的动画 | 待开发 |
| P1 | 操作按钮 | 悔棋、投降、和棋（可选） | 待开发 |
| P1 | 动画效果 | 翻棋、吃子、移动动画 | 待开发 |

## 7. 部署与运维

| 优先级 | 功能 | 描述 | 状态 |
